Marksheet Update Checker

Checks every student's marksheet PDF against the two result lists: did the marks that were updated after the backlog / supplementary exams actually reach the marksheet, and is the grade right for those marks? Produces a formal Excel report.

How it decides

  1. The student is read from the marksheet (Registration No., name, programme, specialization) and found in the lists by Registration / Enrollment No.; name, programme and specialization are cross-checked.
  2. Each course on the marksheet is matched to the list rows by course code or subject name.
  3. Latest list (Updated Supplementary) beats the Older list (Master Backlog). Only a real result counts: in the latest list "To update on TruScholar = Yes"; in the older list "Attendance = Present". Absent / "No" rows are not updates.
  4. Marksheet marks = latest valid result → UPDATED. Anything else → NOT UPDATED (and it says whether the older marks are still showing).
  5. The grade on the marksheet is checked against the marks using the grade scale Excel (Old or New — your choice).
